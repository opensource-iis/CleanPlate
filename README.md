Waste Less is a starter web app for a food-saving rewards platform. The MVP includes:

- consumer sign up and login
- points ledger for meal-saving actions
- empty-plate photo submission with a demo vision-check flow
- clean plate = +50 points; leftover food reduces or subtracts points
- rewards catalog and redemption form
- leaderboard and provider dashboard

## Quick start

1. Create a virtual environment.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the app:
   `python app.py`
4. Open `http://localhost:5000`
